# Security policy

## Supported versions

Security fixes are made for the latest release only. SVNpush updates itself
from **Settings → Check for updates**.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately through GitHub:
[**Report a vulnerability**](https://github.com/FlyToRakib/svnpush/security/advisories/new)
(the **Security** tab of this repository).

Include what you found, how to reproduce it, and the SVNpush version and
operating system. You will get an answer within a week. Once a fix is
released, the advisory is published with credit to you, unless you prefer
otherwise.

Examples of what to report: a way for a project's files or a `.svnpush.json`
to run commands or write outside the plugin folder, a password or API key
reaching a file, a log or an AI provider, or an update that is installed
without a valid signature.
